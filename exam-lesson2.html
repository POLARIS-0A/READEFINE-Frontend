📝 Lesson 2 Official Assessment

Complete all test items below based on Lesson 2: Using Context Clues.

Part I. Identification (10 points)

1. Hints found within a sentence or passage that help readers understand unfamiliar words.

2. Context clue that explains a word by giving its meaning directly.

3. Context clue that gives examples of an unfamiliar word.

4. Context clue that uses an opposite meaning to explain a word.

5. Context clue that uses a similar word to explain an unfamiliar word.

6. The words or sentences surrounding an unfamiliar word.

7. A word whose meaning is not familiar to the reader.

8. The process of using surrounding information to understand a word.

9. A type of context clue that describes what something looks like or how it behaves.

10. Information in a passage that helps readers understand the meaning of a word.

Part II. Multiple Choice (5 points)

1. What are context clues?

2. Read the sentence: "Mia was exhausted after running for two hours, so she rested." What does exhausted mean?

3. Which sentence uses an example as a context clue?

4. Read the sentence: "Unlike his outgoing sister, Mark is shy." What does outgoing most likely mean?

5. What should a reader do when encountering an unfamiliar word?

Part III. Essay (5 points)

Explain how context clues help readers understand unfamiliar words. Give one example of a sentence and explain how its context reveals the meaning of an unfamiliar word.
